# Lune Bakery — เอกสารคู่มือระบบร้านเค้กออนไลน์ & ระบบจัดการหลังบ้าน (Admin)

ระบบ E-commerce สำหรับร้านขายขนมเค้กออนไลน์ระดับพรีเมียม พัฒนาด้วย Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS และฐานข้อมูล SQLite จริง (`data/bakery.db`)

---

## 1. วิธีเปิดใช้งานและเปิดดูเว็บไซต์

เซิร์ฟเวอร์รันอยู่แล้วที่ Port 3000 ในเครื่องของคุณ:

- **หน้าร้านสำหรับลูกค้า (Storefront)**: 👉 [http://localhost:3000](http://localhost:3000)
- **ระบบหลังบ้านแอดมิน (Admin Login)**: 👉 [http://localhost:3000/admin/login](http://localhost:3000/admin/login)
- **หน้าตรวจสอบสถานะคำสั่งซื้อ (Order Lookup)**: 👉 [http://localhost:3000/order-lookup](http://localhost:3000/order-lookup)

*(กรณีเปิดเครื่องใหม่ หรือรันคำสั่งด้วยตนเองในอนาคต: รันคำสั่ง `pnpm dev`)*

---

## 2. ข้อมูลเข้าสู่ระบบผู้ดูแลระบบ (Admin Credentials)

บัญชีแอดมินเริ่มต้นที่สร้างไว้ในฐานข้อมูล:

- **URL เข้าสู่ระบบ**: `/admin/login`
- **อีเมล / Username**: `admin@lunebakery.com` (หรือ `admin`)
- **รหัสผ่าน**: `AdminLune2026!`

> **หมายเหตุความปลอดภัย:**
> - รหัสผ่านถูกเข้ารหัสด้วย **Bcrypt Hash (Salt 10 รอบ)** ลงใน SQLite Database
> - ป้องกัน Brute Force Attack โดยจำกัดการพยายามล็อกอินผิดไม่เกิน 5 ครั้งใน 15 นาที
> - มีการตรวจสอบ Session Cookie แบบ `HTTP-Only` และ `SameSite` ทุกครั้งที่เรียกใช้ API หรือเข้าหน้าแอดมิน หากไม่มีสิทธิ์จะถูกปฏิเสธและ Redirect ไปยังหน้า Login ทันที

## 3. สรุปความสามารถของระบบ (Features)

### 3.1 หน้าร้านสำหรับลูกค้า (Customer Storefront)
1. **หน้าแรก (Homepage - `/`)**:
   - Hero Section ดีไซน์พรีเมียม Modern Minimal Luxury Bakery
   - หมวดหมู่เค้ก (Birthday, Chocolate, Cheesecakes, Fruit, Cupcakes, Custom)
   - สินค้าแนะนำ ดึงข้อมูลจากฐานข้อมูลจริง
   - แบนเนอร์โปรโมชั่นและโค้ดส่วนลดที่ตั้งค่าจากหลังบ้าน (เช่น `LUNE10`)
   - เรื่องราวของแบรนด์ (Brand Story) และข้อมูลติดต่อ
2. **หน้ารวมเค้ก (All Products - `/products`)**:
   - ค้นหาเค้กตามชื่อหรือรสชาติ
   - กรองตามหมวดหมู่
   - เรียงลำดับราคา (ต่ำ-สูง, สูง-ต่ำ), มาใหม่, ยอดนิยม
   - แจ้งเตือนสินค้าหมดสต็อกและป้องกันการสั่งซื้อเกินจำนวนที่มีจริง
3. **หน้ารายละเอียดเค้ก (`/products/[id]`) & Quick View**:
   - ภาพความละเอียดสูง
   - ตัวเลือกขนาดเค้ก (0.5 ปอนด์, 1 ปอนด์, 2 ปอนด์)
   - **ช่องกรอกข้อความเขียนบนหน้าเค้ก (Custom Cake Message)**
   - แสดงจำนวนสต็อกคงเหลือจริงแบบเรียลไทม์
   - สินค้าแนะนำที่เกี่ยวข้องในหมวดหมู่เดียวกัน
4. **ระบบตะกร้าสินค้า (Shopping Cart Drawer)**:
   - เพิ่ม/ลด/ลบสินค้า คำนวณยอดรวมอัตโนมัติ
   - แถบวัดสิทธิ์จัดส่งฟรี (Free Shipping Progress Bar) ซื้อครบ 1,200 บาท ส่งฟรี
   - บันทึกข้อมูลตะกร้าใน LocalStorage ข้อมูลไม่หายเมื่อรีเฟรช
5. **ระบบสั่งซื้อและชำระเงิน (`/checkout`)**:
   - ฟอร์มข้อมูลผู้รับ ที่อยู่จัดส่ง และเลือกวันเวลาที่ต้องการให้ส่งเค้ก
   - รองรับโค้ดส่วนลด ตรวจสอบเงื่อนไขยอดซื้อขั้นต่ำจากฐานข้อมูลจริง
   - ตัวเลือกชำระเงิน: พร้อมเพย์ (PromptPay QR Code), โอนผ่านธนาคาร, ชำระเงินปลายทาง
   - **ตรวจสอบสต็อกและตัดสต็อกสินค้าในฝั่งเซิร์ฟเวอร์แบบ Transaction** ป้องกันการสั่งซื้อเกินสต็อก
6. **หน้าใบเสร็จและติดตามสถานะ (`/order/[id]` & `/order-lookup`)**:
   - สรุปรายละเอียดออเดอร์ ข้อมูลจัดส่ง และข้อความบนหน้าเค้ก
   - แสดง QR Code พร้อมเพย์และเลขบัญชีสำหรับชำระเงิน
   - แสดงสถานะออเดอร์ 6 ระดับ: รอชำระเงิน ➜ รอตรวจสอบ ➜ กำลังอบ ➜ กำลังส่ง ➜ สำเร็จ ➜ ยกเลิก
   - สามารถค้นหาติดตามสถานะได้จากเลขที่ออเดอร์ (เช่น `LN-20261026-XXXX`)

### 3.2 ระบบหลังบ้านแอดมิน (Admin Backoffice)
1. **แดชบอร์ดภาพรวม (`/admin`)**:
   - สรุปยอดขายรวมจริง (คำนวณจากออเดอร์ที่ชำระเงินแล้ว)
   - จำนวนออเดอร์ที่รอดำเนินการ, ออเดอร์ทั้งหมด
   - จำนวนสินค้าทั้งหมด และจำนวนสินค้าที่หมดสต็อก
   - ตารางคำสั่งซื้อล่าสุด
   - การแจ้งเตือนเค้กที่สต็อกเหลือน้อย (&le; 5 ชิ้น)
2. **จัดการสินค้าและสต็อก (`/admin/products`)**:
   - เพิ่มเมนูเค้กใหม่ พร้อมระบบอัปโหลดรูปภาพเข้าเครื่อง (`public/uploads`)
   - แก้ไขราคา, ราคาเดิม, รายละเอียด, สต็อก, ป้ายกำกับ (Best seller, New, Signature)
   - เปิด/ปิดการขาย หรือตั้งค่าเป็นแบบร่าง (Draft) / จัดเก็บ (Archived)
   - ระบบลบสินค้าปลอดภัย (หากเคยมีประวัติการสั่งซื้อ จะเปลี่ยนเป็นสถานะจัดเก็บแทน เพื่อรักษาประวัติคำสั่งซื้อของลูกค้า)
3. **จัดการคำสั่งซื้อ (`/admin/orders`)**:
   - ดูรายการคำสั่งซื้อทั้งหมด พร้อมตัวกรองตามสถานะและค้นหา
   - ดูรายละเอียดลูกค้า ที่อยู่จัดส่ง และข้อความเขียนหน้าเค้ก
   - ปรับเปลี่ยนสถานะคำสั่งซื้อ (เช่น กดส่งเข้าเตาอบ, กดส่งรถเย็น, กดยืนยันชำระเงิน)
   - **ระบบคืนสต็อกอัตโนมัติ:** หากแอดมินกดยกเลิกออเดอร์ ระบบจะคืนจำนวนสินค้ากลับเข้าคลังสต็อกทันที
4. **ตั้งค่าร้านค้า & โปรโมชั่น (`/admin/settings`)**:
   - แก้ไขชื่อร้าน เบอร์โทร อีเมล ที่อยู่ เวลาเปิด-ปิด
   - ตั้งค่าค่าจัดส่งพื้นฐาน และยอดสั่งซื้อขั้นต่ำสำหรับจัดส่งฟรี
   - ตั้งค่าเลขที่บัญชีธนาคารและพร้อมเพย์
   - จัดการโค้ดส่วนลด (สร้างโค้ดใหม่, กำหนดยอดซื้อขั้นต่ำ, เปิด/ปิดการใช้งานโค้ด)
